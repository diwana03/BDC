# BDC 2.3.3-dev161

Projector presentation release for Testing and Live.

## Changes

- Winner Podium now opens blank with **Ready for Reveal**; it no longer reveals 5th place automatically.
- Heats adds **Heats Full Scores · Landscape**.
- Final adds **Final Full Results · Landscape**.
- The new **Projector Tab Loop** lets an operator choose two or more available tabs and rotate them every 5–60 seconds.
- Loop selection, delay, and running state persist in the projector session and continue even if the admin control page is closed.
- Final results and winner views remain protected by **Results Reveal Safety**.
- Testing now uses the same remote controller and public feed engine as Live.

## Deployment

- Branch: `develop`
- No historical migration file was modified.
- No Production configuration was changed.
