# BDC 2.3.3-dev33

## Out-of-division promotion clarity

- Shows an explanation at the top of the leaderboard when **Show Out of Division competitors** is selected.
- Explains that promotion results from exceeding the division's maximum points or previously competing in a higher division.
- Displays **Promoted to [Division]** consistently for either promotion reason.
- Evaluates the points rule before higher-division competition history.

No database migration is required. Production is not deployed by this change.
