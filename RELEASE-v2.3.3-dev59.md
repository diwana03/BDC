# BDC v2.3.3-dev59

## Automatic Heats UI Correction

- Removes the active legacy Automatic Heats layout from the rendered page.
- Automatic Heats now renders the shared Manual-style setup: category/tier settings, judge setup, inline Leader and Follower competitor entry, bib management, and optional Registration Desk link.
- Only the scoring area differs: Manual keeps admin score entry, Automatic shows Judge Live Scoring and secure judge browser links.
- Automatic browser judges use YES / A1 / A2 / A3 and the existing BDC weights.
- Special categories retain fixed point schedules and bypass participant-count point tiering.
- Release Manager workflow is unchanged.
