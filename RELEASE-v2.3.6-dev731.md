# BDC 2.3.6 dev731

## Dance Cup judge call sequence

- Adds a separate **Call Judges One by One** projector screen.
- Shows one large judge card with the saved 4:5 photo preview, judge number, Chief Judge label, full name, flags and countries.
- Adds direct judge selection plus bounded Previous Judge and Next Judge controls.
- Supports optional timed rotation through the existing Auto Page delay control.
- Keeps the existing All Judges and Scoring Progress screens unchanged.
- Uses the existing Dance Cup projection state, so no database migration is required.
