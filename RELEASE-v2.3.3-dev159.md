# BDC v2.3.3-dev159

Build 2489 · Development release · 13 August 2026

## Special-category YES tiers

- Replaces the unrestricted number field with Tier 1 (5 YES), Tier 2 (10 YES), and Tier 3 (15 YES).
- Recommends a default using the larger Leader or Follower participant count.
- Uses 5 for up to 15 competitors, 10 for 16–30, and 15 for 31 or more.
- Allows every Admin Scorer to amend the recommendation before judging.
- Save & Lock now preserves the selected tier across page reloads.
- Unlock remains available only before judge marks exist.
- ALT 1, ALT 2, and ALT 3 stay fixed at 4.5, 4.3, and 4.2.
- Fixed special-category placement points remain independent of the YES tier.
- Testing and Live, Manual and Automatic scoring use the same behaviour.

## Deployment

- No database migration is required.
- No Production configuration is changed.
