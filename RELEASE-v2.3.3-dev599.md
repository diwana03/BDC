# BDC 2.3.3-dev599

## Judge link delivery controls

- Restores Copy Link, Open, WhatsApp and Email actions when an existing plaintext judge token is hidden.
- Rotates the secure token only when the administrator chooses an action.
- Copies or opens the replacement URL immediately.
- Allows WhatsApp and Email delivery to continue without a separate regeneration step.
- Keeps existing marks, judge assignments and scoring progress unchanged.
