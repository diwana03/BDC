# BDC 2.3.3-dev22

## Combined leaderboard and participant photos

- Adds an **All Divisions** leaderboard view.
- Shows each participant once, grouped by the existing competitor or linked career identity.
- Combines approved Leader and Follower points across all divisions into one career total.
- Displays the role breakdown below the total as `L + F`.
- Keeps Novice, Intermediate and Advanced role-specific rankings unchanged.
- Displays the participant's existing profile photo on Participant Results summary cards.
- Uses the default competitor avatar when no profile photo is available.

This release changes the public leaderboard and Participant Results presentation only. It does not rewrite points, placements, participant records, scoring data or database schema.
