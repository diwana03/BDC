# BDC v2.3.3-dev56

## Automatic Heats Workflow Alignment

- Automatic Heats now exposes the same Registration Desk entry point used by the normal Heats workflow.
- Registration Desk provides the existing secure link, Copy Link, Open Registration Desk, live Leader/Follower counts, missing bibs and last update.
- Competitors and bibs continue to be managed through the existing Registration Desk; no separate Automatic registration flow is introduced.
- The Automatic admin Judge Scores entry section is removed from the visible workflow and replaced by Judge Live Scoring.
- Judge Live Scoring provides secure judge URLs, Copy, WhatsApp, Email, Open, live progress, Submit & Lock and audited Super Admin unlock.
- Judge setup remains the existing judge panel with minimum 3 judges and unlimited additional judges.
- Manual scoring, calculation logic, Relative Placement, points logic and Release Manager workflow are unchanged.
