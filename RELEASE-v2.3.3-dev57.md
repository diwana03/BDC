# BDC v2.3.3-dev57

## Special Category Registration Desk Routing Fix

- Automatic scoring now routes Bachata Rising, Bachata Open and Bachata Invitational to the existing special-category Registration Desk instead of the normal Novice/Intermediate/Advanced eligibility validator.
- Special-category competitor search no longer shows the invalid-division eligibility error.
- Existing BDC IDs and competitor records continue to be used.
- New provisional competitors created through a special-category desk remain Novice in BDC progression, consistent with the special-category point-bucket rules.
- Special-category labels display as Bachata Rising, Bachata Open and Bachata Invitational instead of underscored database values.
- Manual/Automatic scoring calculations and Release Manager workflow are unchanged.
