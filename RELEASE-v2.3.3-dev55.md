# BDC v2.3.3-dev55

## Scoring Mode Visibility

- Saved Rounds now shows a dedicated Scoring Mode column.
- Automatic rounds use a blue AUTOMATIC badge and subtle blue row tint.
- Manual rounds use a dark MANUAL badge and subtle neutral row tint.
- The Saved Rounds dashboard heading is now neutral: BDC Scoring Engine · Event Round Workflow.
- Opening a saved round now preserves its stored scoring mode in the URL so Automatic rounds reopen as Automatic and Manual rounds reopen as Manual.
- Scoring calculations, Registration Desk, judge browser scoring, point logic and Release Manager workflow are unchanged.
