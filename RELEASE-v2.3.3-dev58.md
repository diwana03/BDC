# BDC v2.3.3-dev58

## Automatic Scoring Alignment

- Automatic Heats now mirrors the Manual Heats setup: category/tier settings, judge setup, inline Leader/Follower competitor entry, bib management and optional Registration Desk link.
- The Registration Desk link is optional; competitors can be entered directly on the scoring dashboard.
- Special categories use the same shared registration UI and bypass normal Novice/Intermediate/Advanced entry progression checks.
- Bachata Rising and Bachata Open show fixed 5/4/3/2/1 points; Bachata Invitational shows fixed 3/2/1 points. Participant-count tiering does not alter special-category points.
- Judge scopes and Chief Judge selection remain unchanged.
- Automatic judge browser scoring now uses the same Heats choices as Manual scoring: YES, A1, A2 and A3 with the existing locked BDC weights.
- Judge browser links no longer depend on the abandoned separate setup-confirmation workflow. Links become available after a valid judge panel and active Leader/Follower entries exist.
- Judge links retain Copy, WhatsApp, Email, Open, live progress, Submit & Lock and Super Admin audited unlock.
- Final browser judging continues to use Relative Placement ranks.
- Release Manager workflow is unchanged and no staging deployment is performed by this release.
