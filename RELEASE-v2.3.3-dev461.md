# BDC 2.3.3-dev461

## Event-first Dance Cup workspace

- Replaces the flat category picker with one section per Dance Cup event.
- Displays every category directly beneath its parent event.
- Shows event date, venue, country and category count once instead of repeating the event name on every card.
- Adds direct Open and Edit actions to each scoring category.
- Keeps protected Delete available only for Draft categories.
- Uses a three-column PC layout, two-column tablet layout and single-column mobile layout.
- Preserves Live/Test and Manual/Automatic/Projection isolation.

No scores, marks, judging panels, judge links, rankings or projection behavior are changed.
