# BDC v2.3.3-dev158

Build 2488 · Development release · 13 August 2026

## Special-category scoring controls

- Every Admin Scorer can choose the number of YES selections required per judge.
- The chosen YES count can be saved and locked before judging.
- Admin Scorers can unlock and revise the count while no judge marks exist.
- Once judging begins, the setting cannot be changed or unlocked.
- ALT 1, ALT 2 and ALT 3 remain fixed at 4.5, 4.3 and 4.2.
- The same behaviour is available in Testing and Live, for Manual and Automatic scoring.
- Special-category fixed placement points remain unchanged.

## Archived events

- Archived events now sort by event date from latest to oldest.
- Events without a date appear last.
- Archive time and event ID provide stable tie-breaking.

## Deployment

- No database migration is required.
- No Production configuration is changed.
