# BDC 2.3.3-dev167

## Live Random Matching Presentation

- Replaces the previous follower `shuffle()` with secure Fisher–Yates randomization using `random_int()` in Testing and Live.
- Records the algorithm, timestamp, participant counts, pairing payload and SHA-256 audit reference for each random draw.
- Adds an independent Emcee Match Link that cannot access scores, judge votes, results or administrative controls.
- Emcee links expire after 12 hours, become invalid when pairing is confirmed, and can be regenerated by an administrator.
- Adds a projector Random Final Match screen and live data refresh.
- Adds projector drum-roll, fireworks and confetti presentation effects.
- Keeps every generated match as Draft until Chief Judge/Admin confirmation.
- Makes Live Projection a top-level dashboard navigation item.

## Judge Link Security

- New and regenerated Testing and Live judge scoring links expire after 12 hours.
- Existing links receive a guarded 12-hour expiry during schema synchronization.
- Submitted scoring remains locked as before.
