# BDC 2.3.3-dev11

## Participant Results

- Adds an Aggregate Points summary above participant search history.
- Shows Intermediate points first, followed by Novice points, for contestants who have earned Intermediate points.
- Shows only the Novice total when a contestant has no Intermediate points.
- Uses the existing point transaction ledger and does not alter scoring, eligibility, promotion thresholds or stored results.
- Keeps each matching competitor separate when a search returns more than one person.

## Safety

No database schema, scoring formula, repository document or publishing workflow changed.
